# LidiCrochê - Landing Page

---

## 📂 Estrutura do Código

O projeto é composto por três partes principais:

* **HTML (`index.html`)**:
* Estrutura a marcação semântica do site.


* Contém o cabeçalho fixo com links de navegação rápida (*Início, Catálogo, Diário, Sobre* e botão de contato para o WhatsApp).


* Possui a seção principal (*hero*) com imagens de destaque, títulos e chamadas para ação (CTAs).




* **CSS (`css/style.css`)**:
* Gerencia o estilo visual, paleta de cores, tipografia, espaçamentos e o design responsivo da página para diferentes tamanhos de tela.




* **JavaScript (`js/script.js`)**:
* Controla os scripts de interatividade e comportamentos dinâmicos do lado do cliente (*client-side*).
